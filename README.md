# Mod Menu для Geometry Dash (Geode v5)

Мод-меню: открывается по F1 или кнопкой с шестерёнкой в левом верхнем углу главного экрана.

Функции: Noclip, Safe Mode, Show FPS, Speedhack.

## Сборка

Сборка идёт автоматически на GitHub Actions при каждом пуше в ветку `gd-modmenu`.
Готовый файл `user.modmenu.geode` лежит в Artifacts запуска («Build Output»).
Положи его в папку `geode/mods` рядом с игрой.

Примечание: на очень новых версиях GD Noclip и Safe Mode могут не работать, пока Geode
не получит поддержку этой версии. Меню, кнопка, Speed и Show FPS от адресов игры не зависят.
